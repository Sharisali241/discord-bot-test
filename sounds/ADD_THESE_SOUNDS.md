# Add Your Meme Sounds Here

The bot plays any **.mp3**, **.wav**, **.ogg**, **.flac**, or **.m4a** file in this folder.  
Use the **filename without extension** as the command: e.g. `dil_dil_pakistan.mp3` → `!play dil_dil_pakistan`

**No sounds download.** The bot does not download any audio. You must add all sound files yourself to this folder.

## How to add

1. Get the audio yourself (YouTube, meme sites, your own recording – respect copyright). **The bot does not download sounds.**
2. Convert to MP3 if needed (online converter or Audacity).
3. Name the file exactly as in the list (e.g. `dil_dil_pakistan.mp3`).
4. Put it in this `sounds` folder.
5. Restart the bot (or it will load new files on next guild use).
6. In Discord: `!play dil_dil_pakistan` (or `!library` to see all).

You already have **saanso.mp3** – use `!play saanso` to test.
